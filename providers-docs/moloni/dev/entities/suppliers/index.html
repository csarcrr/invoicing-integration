Entities | Suppliers

Administrar os fornecedores de uma empresa.

count
Devolve a quantidade de fornecedores de uma empresa.
getAll
Devolve todos os fornecedores de uma empresa.
getOne
Devolve os detalhes de um fornecedor.
countBySearch
Devolve a quantidade de fornecedores com base nos resultados de uma pesquisa no campos do cliente. Os campos pesquisados são: Número, Contribuinte e Nome.
getBySearch
Devolve fornecedores com base nos resultados de uma pesquisa no campos do cliente. Os campos pesquisados são: Número, Contribuinte e Nome.
countByVat
Devolve a quantidade de fornecedores com base numa pesquisa por número de contribuinte.
getByVat
Devolve fornecedores com base numa pesquisa por número de contribuinte.
countByNumber
Devolve a quantidade de fornecedores com base numa pesquisa por número de cliente.
getByNumber
Devolve os fornecedores com base numa pesquisa por número de cliente.
countByName
Devolve a quantidade de fornecedores com base numa pesquisa por nome.
getByName
Devolve os fornecedores com base numa pesquisa por nome.
insert

update
Actualiza um fornecedor. Se o fornecedor já estiver referenciado em documentos, não é possível alterar o número de contribuinte e o número de fornecedor. Qualquer alteração destes dois ca...
delete
Elimina um fornecedor. Não é possível eliminar fornecedores que já estejam referenciados em documentos. A tentativa obterá uma resposta inválida da API ( valid: 0 ).
