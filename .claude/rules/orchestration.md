# Orchestration

- Delegate to the `builder` subagent without asking: provider docs extraction, Pest tests from an approved mapping table, `docs/` updates after code changes, multi-file mechanical sweeps, and inventories.
- Keep in the main session: field-mapping decisions, contract and Action design, implementation that needs judgment, and reviews.
- Every brief lists the goal, files to read, constraints, and a `Done when:` checklist.
- Check the builder report against the brief before accepting it. Run `reflect` when a report misses the brief.
